# Getting started

Use this guide after installation. Give the user the panel link and the next
step for their intended task. Keep existing working connections.

1. **Sign in to OneCrew.** Open the verified local panel address and complete
   OneCrew sign-in in the browser when signed out.
2. **Connect the search platform.** In Accounts, select the platform needed for
   the task. YouTube public search uses a YouTube Data API v3 API Key. X,
   Instagram, Facebook and TikTok use Cookie-Editor JSON from a signed-in browser.
   Follow the relevant [FAQ steps](faq.md#account-connections). The user enters
   credentials in the local panel; keep them out of chat.
3. **Connect a mailbox for sending and replies.** Open Email → Manage mailboxes
   and connect the sender. Creator search does not require a mailbox.
   See [Email workflows](email.md).
4. **Start a task.** Select OneCrew in the AI client and describe the task.
   For example:

   - “Find 20 US YouTube creators who make paper crafts and save them to a table.”
   - “Show my saved creators and their contact status.”
   - “Draft an invitation for these creators.”

OneCrew sign-in, search-platform credentials and mailbox connections are separate.
